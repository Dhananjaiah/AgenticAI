# Agentic AI Insurance Claims - Complete Course

## Welcome to the Course! 🎉

Hello and welcome! If you're reading this, you want to understand how to build an AI-powered insurance claims system. Don't worry if you're new to this - I'll explain everything in simple terms, step by step.

**Who is this course for?**
- Beginners who want to learn about AI agents
- Developers who want to understand production AI systems
- Anyone curious about how AI can handle insurance claims

**What will you learn?**
By the end of this course, you'll understand:
- How AI agents work together to process insurance claims
- How to retrieve data from multiple sources (databases, SharePoint, cloud storage)
- How to remove duplicate documents automatically
- How to use AI to summarize and analyze claims
- How to build a production-ready API
